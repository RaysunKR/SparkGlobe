# Document Processing Skills

PPTX, PDF, DOCX, XLSX file creation, parsing, and canvas design skills.

## Best For

- Creating presentations (PPTX)
- Generating PDF documents
- Creating Word documents (DOCX)
- Creating spreadsheets (XLSX)
- Canvas-based design generation

## Skills

| Skill | Installs | Install Command | Description |

| pptx | 128.7K | `npx skills add anthropics/skills/pptx` | Create, read, and edit PowerPoint presentations |

| canvas-design | — | `npx skills add anthropics/skills/canvas-design` | Design generation and iteration in canvas environments |
