# Browser Automation Skills

Web automation, form filling, screenshot capture, data extraction, and browser control skills.

## Best For

- Automating browser interactions
- Web scraping and data extraction
- Testing web applications
- Filling forms and clicking buttons
- Taking screenshots programmatically

## Skills

| Skill | Installs | Install Command | Description |
|-------|----------|----------------|-------------|
| agent-browser | 330.1K | `npx skills add vercel-labs/agent-browser/agent-browser` | Full browser automation: navigate, click, fill forms, extract data, screenshot |
| browser-use | 77.5K | `npx skills add browser-use/browser-use/browser-use` | Browser automation with visual understanding — interacts based on what it sees |
| hyperframes | 78.3K | `npx skills add heygen-com/hyperframes/hyperframes` | Video/animation frame generation from web content |
| hyperframes-cli | 74.3K | `npx skills add heygen-com/hyperframes/hyperframes-cli` | CLI tool for hyperframes |
| gsap | 74.0K | `npx skills add heygen-com/hyperframes/gsap` | GSAP animation integration |
| website-to-hyperframes | 71.9K | `npx skills add heygen-com/hyperframes/website-to-hyperframes` | Convert websites to animated frames |
| just-scrape | 97.3K | `npx skills add scrapegraphai/just-scrape/just-scrape` | AI-powered web scraping |
