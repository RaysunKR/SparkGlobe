# 移动端技能

React Native、Expo、原生平台开发与移动端 UI 相关技能。

## 推荐场景

- 构建 iOS/Android 原生应用
- Expo 开发与 SDK 升级
- 移动端 UI 与原生组件集成
- 移动端数据获取与离线缓存

## 技能列表

| 技能名称 | 安装量 | 安装命令 | 说明 |
|---------|--------|---------|------|
| vercel-react-native-skills | 131.3K | `npx skills add vercel-labs/agent-skills/vercel-react-native-skills` | React Native 最佳实践：性能、导航、原生模块与平台 API |
| sleek-design-mobile-apps | 182.3K | `npx skills add sleekdotdesign/agent-skills/sleek-design-mobile-apps` | 移动优先设计模式：手势、安全区域与原生体验 |
| building-native-ui | — | `npx skills add expo/skills/building-native-ui` | Expo 原生 UI 组件：列表、模态框、Tab、底部弹出与触觉反馈 |
| native-data-fetching | — | `npx skills add expo/skills/native-data-fetching` | 原生应用数据获取：离线缓存、后台刷新与同步模式 |
| expo-tailwind-setup | — | `npx skills add expo/skills/expo-tailwind-setup` | NativeWind 与 Tailwind 在 Expo 中的配置 |
| upgrading-expo | — | `npx skills add expo/skills/upgrading-expo` | Expo SDK 升级指南：破坏性变更、原生模块兼容性与迁移步骤 |
