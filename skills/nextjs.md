# Next.js 技能

Next.js App Router、Server Components、缓存策略与 Vercel 部署相关技能。

## 推荐场景

- 构建 Next.js 全栈应用
- 优化 Server Components 与数据获取
- 配置缓存策略（PPR、cacheLife、revalidateTag）
- 部署到 Vercel 平台
