# 数据库技能

PostgreSQL、Supabase、Firebase、Convex、Neon、PlanetScale、Turso、DuckDB 与 ORM 相关技能。

## 推荐场景

- 数据库 schema 设计与查询优化
- Supabase/Firebase 后端搭建
- 数据迁移与扩展
- ORM 集成（Drizzle）
